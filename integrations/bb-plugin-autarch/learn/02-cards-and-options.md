# Cards and options: how a pick works

A card states one question, the options and a recommendation. Picking an option is your ruling on that card. Home delivers the pick to the thread that asked: the one that wrote the card's first agent comment. Later comments do not change who gets it.

- A pick is not merge, deploy, release or publish authorization unless the card says so.
- "Other" lets you ask or note something instead of picking. It never rules or closes the card.
- Each card should be complete on its own: if one is not, say so in a note.
