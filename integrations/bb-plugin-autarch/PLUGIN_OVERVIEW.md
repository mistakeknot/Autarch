Keep what is waiting for you in one place, in the sidebar and in your agent threads.

## What you get

- A **Home** page in the left sidebar with the asks waiting for a ruling, a catch-up
  feed of what happened while you were away, the vizier thread, and delegation settings.
- A `bb home` command that lets agents file asks and report blocker progress.
- An **Example todos** page that adds, completes, and removes todos.
- Live updates, so a change made in one place reaches every open page at once.

## How it works

Home data lives in this plugin's own storage on the BB server. The plugin talks to a local
Autarch service on this machine and needs no account, API key, or external service.

## For agents

The bundled skill tells an agent to look up asks with `bb home get`, file one with
`bb home ask`, and report blocker progress with `bb home progress` and `bb home resolve`.
