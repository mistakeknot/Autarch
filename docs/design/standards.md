# Project workbench design standards

Accepted product direction, September 9, 2026. These standards describe the
target project visit; they do not imply the complete workbench is implemented.

Use the existing Bubble Tea and Lip Gloss components, Tokyo Night palette and
Cozy/Compact density choices. Density changes spacing and how much fits, not
which evidence or authority a person can inspect.

Show artifacts, outcomes, relevant evidence and pending decisions with Flere's
conversation beside them. Below 100 columns, stack the artifact and conversation
panes with independent scrolling and keyboard focus. Subtract chrome before
allocating pane sizes; preserve selection and drafts when resizing.

The outcome/decision view and map view are directly switchable. Remember the
choice per project and keep the same selected entity and conversation. Offer
purpose-to-work and theme layouts; pace is a filter or annotation across both.
Map edges distinguish sourced observations from provisional inferences.

Ask one multiple-choice question at a time and accept free-text corrections.
Use concrete experience comparisons to discover taste. Show what a synthesis
changes, why it changes it, which sources it uses and what remains uncertain.
Acceptance, plan preparation and implementation start are separate actions.

Keep original evidence readable beside summaries. Missing sources, stale
revisions, conflicting rulings and unknown project context must remain visible.
Do not use colors or confidence scores as substitutes for authority labels.

Keyboard commands must not consume ordinary text entry. Preserve accessible
focus and visible action labels in both densities. Existing
[engineering conventions](../../agents/conventions.md) continue to apply; the
workbench-specific layout here supersedes the blanket 50/50 chat-first rule for
this journey only. The estate overview retains its quiet orientation purpose.

Prototype unresolved interaction choices in a running TUI at wide and narrow
sizes before freezing the technical plan. Record usability judgment separately
from automated resize and state-retention checks.
