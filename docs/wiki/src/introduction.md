# Autarch

Autarch is a Go monorepo of tools for developing with AI agents, plus a TypeScript plugin (`integrations/bb-plugin-autarch`) that adds the Home decision queue to bb.

Every number and name below is checked against the code by `docs/wiki/figures_test.go`, which runs in `go test ./...`. A figure is written as a marker comment, for example `<!-- figure:cmd-count=11 -->`, directly before the sentence that uses it. If the code changes and the page does not, the test fails.

This wiki is private source documentation. It is not published anywhere.
