# Sourced working context across runtimes

Status: accepted direction; runtime implementation and evaluation pending.
Authority: [mk's September 9 instruction](2026-09-09-human-ratification.md).

Keep one continuous project visit and its original transcript. Supply each
runtime a compact working state with applicable rulings verbatim, essential
rationale, current outcome, exact corrections, open questions, completed
actions, and current source and plan bindings. Retrieve supporting passages and
code context as needed, with source references and explicit coverage limits.

Never silently truncate mandatory guidance to fit a budget. If it does not fit,
report insufficient budget or incomplete coverage. Missing or stale evidence
does not become an empty result or permission to invent a ruling. Superseded
answers remain recoverable evidence, and a runtime handoff is visible.

Compare compact sourced handoffs with and without graph retrieval on identical
tasks and model settings. Use known rulings and expected evidence; require
guidance retention and independent plan-quality assessment before considering
token savings. Count retrieval, indexing, retries and corrections in total
cost. Unknown usage remains unknown.

Alternatives rejected: replay every transcript for every task, or discard it
after summarizing. The first has unbounded cost; the second loses the evidence
needed to correct a summary. No retention or cost benefit has yet been measured.
